# DevSecOps Projects

This portfolio starts with the Docusaurus Blog project, followed by V-Server Setup and the other DevSecOps projects.

- [Docusaurus Blog](./docusaurus-blog.md) — this documentation site, its configuration, and its GitHub Pages workflow.
- [V-Server Setup](./v-server-setup.md) — SSH access, NGINX, and GitHub connectivity documented in a reproducible server setup guide.
- [Baby Tools Shop](./baby-tools-shop.md) — containerizing a Django shop with persistent SQLite and uploaded media.
- [Minecraft Server](./minecraft-server.md) — building a Fabric-enabled Java server image with persistent world data.
- [WordPress Multi-Container Setup](./wordpress-multicontainer-setup.md) — running WordPress and MariaDB as separate Compose services with health-aware startup and persistent data.
- [Conduit Container](./conduit-container.md) — combining an Angular frontend, Django backend, and PostgreSQL database in a persistent Compose stack.
- [Conduit Deployment](./conduit-deployment.md) — building versioned images in CI and deploying the existing stack to a staging VPS through GitHub Actions.
- [Truck Signs API](./truck-signs-api.md) — repairing the supplied Django API's Docker Compose stack with internal PostgreSQL and persistent data.
