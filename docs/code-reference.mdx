# Code Reference

<Link to="pathname:///code-reference/index.html" target="_self">Open the generated code reference</Link>

The reference documents this learning journal's home and legal-notice pages.
It is generated from the TypeScript source and TSDoc comments with TypeDoc
each time the website is built.

Pages appear under their declared function names, `Home` and `Imprint`.
A small local TypeDoc plugin applies these names to the reference; the
application continues to use default exports.

Third-party code, unchanged template helpers, CSS rules and deployment settings
are outside the generated reference. The repository README explains setup,
configuration and deployment. Project reports describe the separate training
projects.

## Working with the documentation

After installing the application dependencies, install the documentation tools:

```bash
npm run docs:install
```

Regenerate only the reference after editing a comment or a documented export:

```bash
npm run docs:build
```

`npm start` generates the reference before starting the development server.
Regenerate it manually after subsequent source changes. `npm run build` generates
it before building the website, so the production output includes the current
reference. Generated HTML is ignored by Git.

The small package under `tools/code-docs/` keeps TypeDoc and its compatible
TypeScript 6 compiler separate from the application's TypeScript 7 compiler.
The application typecheck remains independent of documentation generation.
